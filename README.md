# memo_app

## セットアップ手順
### 1. 前提条件

・Python 3.8 以上


### 2. ローカル環境でのセットアップ

1.リポジトリのクローン

```
git clone [このリポジトリのURL]
```
2.仮想環境の作成と有効化


```
#macの場合(ターミナル)
export FLASK_APP=flaskr
export FLASK_ENV=development

#windows(CMD)
set FLASK_APP=flaskr
set FLASK_ENV=development

#windows(Powershell)
$env:FLASK_APP="flaskr"
$env:FLASK_ENV="development"

```


3.アプリケーションの起動
以下のコマンドで開発サーバーを起動します。


```
flask run --debug
```


ブラウザで http://127.0.0.1:5000 にアクセスすると、アプリケーションが表示されます。


## 使い方

### メモの追加

1.トップページの上部にある入力フォームにメモの内容を入力します

2.メモの内容から自動でカテゴリーが分類されます。

3.「保存」ボタンをクリックするとメモが保存され一覧の下に追加されます


### メモの検索

1.トップページにある「過去のメモを検索する」リンクをクリックし、検索専用ページに移動します。

2.検索フォームで、以下の条件を1つ以上指定します。

・カテゴリ: ドロップダウンリストから選択します。

・フリーワード: メモ本文に含まれるキーワードを（大文字・小文字を区別せず）入力します。

・記入日: `YYYY-MM-DD`形式で日付を指定します。

3.「検索」ボタンをクリックすると、指定した条件にすべて一致するメモが下に表示されます。

### カテゴリ分類ルールの説明

メモを保存する際、ユーザーがカテゴリを指定しなかった場合は、メモの本文(content)に以下のキーワードが含まれているかを判定し自動でカテゴリを割り振ります。

・「会議」「打ち合わせ」→ Meeting
 
・「買い物」「購入」→ Shopping

・「TODO」「やること」→ Task

・上記いずれにも当てはまらない場合は Other
